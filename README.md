# Armonia

**Compose harmonious color relationships. Watch chaos become beauty.**

Armonia is an interactive color harmony game where you drag vibrant swatches into slots to create balanced color combinations. Unlock harmony types—from complementary to triadic—and watch generative art respond to your palette choices in real-time.
